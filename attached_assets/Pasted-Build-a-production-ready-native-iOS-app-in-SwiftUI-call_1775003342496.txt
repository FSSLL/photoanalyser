Build a production-ready native iOS app in SwiftUI called Photo Finder AI.

Goal:
Create an iPhone app that can:

Request access to the user’s photo library.
Read and index the user’s photos locally.
Let the user search photos by natural-language descriptions such as:
“red car”
“coffee cup on a table”
“sunset at the beach”
“documents with text”
“pictures of cats”
Show matching photo results in a fast grid UI.
Open a photo in detail view.
Allow the user to select one or multiple photos and delete them safely with confirmation.
Keep privacy-first behavior: do not upload any photos unless explicitly enabled later.

Technical requirements:

Use SwiftUI for the full UI.
Use PhotoKit for photo library access, fetching assets, thumbnails, metadata, and deletion.
Support both full photo access and limited photo access.
Use PHPhotoLibrary authorization flow properly.
Use PHCachingImageManager or equivalent thumbnail caching for performance.
Use Vision + Core ML for image understanding.
Build a local indexing pipeline:
fetch photos from the library
generate image embeddings or tags for each image
store searchable index locally in SQLite or Core Data
allow re-indexing and incremental updates when the library changes
Add PHPhotoLibraryChangeObserver support so the index stays synced if the gallery changes.
For text search:
convert the text prompt into a comparable embedding or searchable representation
rank results by similarity score
show confidence or relevance score if available
If a true multimodal text-image embedding model is not available by default, structure the app with a clean abstraction so I can later swap in:
an on-device Core ML model
or a private backend embedding API
The first version should default to fully local / on-device processing as much as possible.

Deletion behavior:

User must be able to:
select one photo
select multiple photos
delete selected photos
Always show a confirmation sheet before deletion.
Use the correct PhotoKit delete flow.
Handle failure states clearly.
Never auto-delete anything without explicit user action.
Add an optional “Review before delete” mode.
